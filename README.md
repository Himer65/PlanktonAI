# Бот для игры в шахматы

**PlanktonAI** — это минималистичная нейросетевая модель для игры в шахматы, оптимизированная для работы на клиентской стороне (CPU) с крайне низкой задержкой. Модель обучается с подкреплением (REINFORCE с baseline). Обучена путем самоигры. 

---

## Свойства бота
### Версия 8
- **Количество параметров** – **15511**  
- **Время одного инференса на CPU** – **~92893.43 ns** (замерено на AMD Ryzen 7 4800H with Radeon Graphics, ONNX Runtime)

---

## Архитектура сети

Модель представляет собой **нейросеть**, состоящую из свёрточных слоёв для обработки доски, полно связных слоёв для учёта контекстных признаков (правило 50 ходов, рокировки, очерёдность хода, взятие на проходе), и четырёх выходных голов, каждая из которых выдаёт распределение вероятностей по координатам начальной (from_x, from_y) и конечной (to_x, to_y) клеток хода.

### Входные данные
- **Board** – тензор размером `[8, 8]`, где каждая клетка кодируется целым числом от 0 до 12 (смотри переменную _piece в [dataset.py](dataset.py)).  
- **Context** – 7 числовых признаков:
  - `halfmove_clock` / 50 (нормализованный счётчик ходов без взятия)
  - право на рокировку в короткую сторону для черных (0 или 1)
  - право на рокировку в длинную сторону для черных (0 или 1)
  - право на рокировку в короткую сторону для белых (0 или 1)
  - право на рокировку в длинную сторону для белых (0 или 1)
  - очередность хода (1 черные -1 белые)
  - взятие на проходе (нормализованный индекс клетки)
