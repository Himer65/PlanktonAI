# Бот для игры в шахматы

**PlanktonAI** — это минималистичная нейросетевая модель для игры в шахматы, оптимизированная для работы на клиентской стороне (CPU) с крайне низкой задержкой. Модель обучается с подкреплением (REINFORCE с baseline) и играет за чёрные фигуры. Обучена на рандомных ходах противника. 

---

## Свойства бота

### Версия 7
- **Количество параметров** – **9 498**  
- **Время одного инференса на CPU** – **~43242.94 ns** (замерено на AMD Ryzen 7 4800H with Radeon Graphics, ONNX Runtime)

---

## Архитектура сети

Модель представляет собой **полносвязную нейросеть** с одним скрытым слоем и четырьмя выходными головами, каждая из которых выдаёт распределение вероятностей по одной из координат хода (откуда и куда).

### Входные данные
- **Board** – тензор размером `[8, 8]`, где каждая клетка кодируется целым числом от 0 до 12 (смотри переменную _piece в [dataset.py](dataset.py)).  
- **Context** – три числовых признака:
  - `halfmove_clock` / 150 (нормализованный счётчик ходов без взятия)
  - право на рокировку в короткую сторону для черных (0 или 1)
  - право на рокировку в длинную сторону для черных (0 или 1)

## Планы по развитию

1. **Увеличение числа игр** – обучение на 10 000+ эпизодов для повышения силы игры.
2. **Переход на свёрточную архитектуру** – лучшее восприятие пространственных паттернов.
3. **Самоигра (Self‑play)** – обучение против самой себя вместо случайного соперника.
4. **Алгоритм Actor‑Critic** – снижение дисперсии градиентов и ускорение сходимости.
5. **Интеграция с веб‑интерфейсом** – запуск модели на моём сайте <https://himer65.github.io/ai/index.html>.
